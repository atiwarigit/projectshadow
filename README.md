# Kind Shadow Club

A mutual-aid room on the ZClub porch. Privacy is the default, kindness is the action.

**Live:** [atiwarigit.github.io/projectshadow](https://atiwarigit.github.io/projectshadow/)

One self-contained landing page. No build step, no dependencies, no server.

## Files

- `index.html` — the entire site
- `404.html` — branded miss
- `favicon.svg` — ears mark
- `robots.txt` — allow indexing
- `vercel.json` — ready for a later Vercel project

## Local

```bash
python3 -m http.server 4173
```

Then visit `http://localhost:4173`.

## Guardrails

Social only. Credits are recognition, not tokens. The pool is mutual aid, not a yield. Not official Zcash. Not financial advice.
